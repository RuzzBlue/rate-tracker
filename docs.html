Documentación & Guía de Transparencia de Precios

Manual técnico completo sobre la captura automatizada de tasas USDT de Banco BISA, arquitectura anti-caché, auditoría fotográfica y publicación en GitHub Pages.

1. ¿Qué hace este sistema?

Este portal registra diariamente las cotizaciones oficiales de compra y venta de USDT (Tether) y la tasa USDT/USD publicadas por Banco BISA S.A. en Bolivia (bisa.com/home).

Para garantizar a los clientes una transparencia total, cada captura se almacena en una base de datos histórica inmutable (rates.json) y se acompaña de una captura de pantalla fotográfica en alta resolución tomada en el segundo exacto en que la cinta de cotizaciones muestra los valores, con una marca de agua de fecha y hora generada en la página.

2. Arquitectura de Captura y Protección Anti-Caché

Banco BISA utiliza sistemas de caché perimetral (CDN Akamai) y enrutamiento SPA (Angular) que en ocasiones pueden retener cotizaciones de días anteriores si no se fuerza una recarga limpia. Nuestra automatización implementa los siguientes protocolos de seguridad:

  • Entorno 100% Aislado (WSL2 Ubuntu): Todas las dependencias (Playwright, Chromium headless y Python) corren dentro de una máquina virtual ligera Linux en ~/.virtualenvs/bisa-tracker. Nada se instala de manera global en Windows.
  • Perfiles de Navegador Efímeros: Cada ejecución a las 11:00 AM inicia una instancia limpia e incógnita sin cookies ni caché residual previo.
  • Cabeceras de Red Estrictas: Se envían solicitudes HTTP con Cache-Control: no-cache, no-store, must-revalidate y Pragma: no-cache.
  • Recarga Forzada en el DOM: Antes de extraer los datos, el navegador ejecuta una recarga limpia de la página y valida los componentes en vivo.
  • Detección de la Cinta Animada: El script supervisa el bucle CSS de 40 segundos de la cinta (.marquee-container). Cuando los elementos de USDT entran completamente en el campo de visión, congela la animación para evitar desenfoque por movimiento y estampa la hora y fecha exacta antes de tomar la captura.

Documentation & Price Transparency Guide

Comprehensive technical manual on automated capture of Banco BISA USDT rates, anti-cache architecture, photographic audit trail, and GitHub Pages deployment.

1. What does this system do?

This portal automatically records daily official buying and selling exchange rates for USDT (Tether) and the USDT/USD rate published by Banco BISA S.A. in Bolivia (bisa.com/home).

To ensure complete transparency for customers, every capture is permanently recorded in a structured database (rates.json) and paired with a high-resolution photographic screenshot taken the second the ticker ribbon displays the values, watermarked with an on-page date and timestamp.

2. Capture Architecture & Anti-Cache Protection

Banco BISA uses edge caching (Akamai CDN) and client-side SPA routing (Angular) that can sometimes serve stale rates from prior days if not properly bypassed. Our automation enforces the following protocols:

  • 100% Isolated Environment (WSL2 Ubuntu): All dependencies (Playwright, headless Chromium, and Python) run inside a lightweight Linux virtual environment at ~/.virtualenvs/bisa-tracker. Nothing touches your global Windows setup.
  • Ephemeral Browser Sessions: Each run at 11:00 AM launches a clean incognito profile with zero residual cache or cookies.
  • Strict Cache-Bypass Headers: HTTP requests explicitly send Cache-Control: no-cache, no-store, must-revalidate and Pragma: no-cache.
  • Forced In-DOM Reload: Before data extraction, the browser executes a forced page reload and verifies the live DOM.
  • Smart Ribbon Detection: The automation tracks the 40-second animated marquee loop (.marquee-container). Once USDT rates are fully centered in the viewport, it pauses the animation to eliminate motion blur and stamps the exact date and time before saving the screenshot.

Why run the capture locally instead of on GitHub Actions? Banco BISA is protected by Akamai Bot Manager, which blocks cloud datacenter IP ranges (such as GitHub Actions or AWS) with an HTTP 503 error. By running locally on your home/office connection, Akamai recognizes it as an authentic user.

Initial Repository Setup:

  1. Create a repository on GitHub (e.g. bisa-rate-tracker).
  2. In PowerShell run:

    git init

    git remote add origin https://github.com/YOUR_USERNAME/bisa-rate-tracker.git
  3. Double-click push_to_github.bat to push files.
  4. In GitHub, go to Settings > Pages, set Source to Deploy from a branch, choose main branch and /(root), and click Save.

Customer Updates: Whenever you want to publish updated metrics to your clients, simply double-click push_to_github.bat. It stages all new data and screenshots and pushes to GitHub within seconds.
